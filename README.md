# Fixer

Браузерный 3D-экшен с открытым миром в духе GTA III: Москва 90-х, советский автопром, милиция.

## Запуск
Откройте `index.html` через любой локальный веб-сервер, например:

```
npx serve .
# или
python3 -m http.server
```

Three.js r128 подгружается с jsDelivr, нужен интернет.

## Управление
- **ПК:** WASD — движение, Shift — бег, мышь (клик захватывает курсор) — свободный обзор, ЛКМ — огонь, E/F — сесть в машину, C — вид от 1-го/3-го лица.
- **Телефон:** левый стик — движение, правый палец — обзор, экранные кнопки. На мобильных автоматически включается облегчённая графика.

## Структура
| Файл | Назначение |
|---|---|
| core.js | карта, ввод, звук |
| touch.js | сенсорное управление, режим LITE |
| ents.js, logic.js | машины, пешеходы, ИИ, физика |
| police.js | милиция: свидетели, розыск, блокпосты, ОМОН, вертолёт, задержание |
| tex.js | процедурные PBR-текстуры |
| gfx.js | рендерер, свет, постобработка |
| world3d.js, arch3d.js | улицы и московская архитектура |
| cars3d.js | модели машин |
| people3d.js | модели людей |
| render3d.js | камера, синхронизация сцены |
| hud.js, main.js | интерфейс и игровой цикл |
